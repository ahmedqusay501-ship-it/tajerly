# معاينة رابط خاصة بكل متجر (تاجرلي)

الموقع على GitHub Pages (ملفات ثابتة)، وزاحف تيليجرام/واتساب ما يشغّل JavaScript، فلازم طبقة تعدّل الـ HTML قبل ما يوصله.
هذا الـ Worker يقرأ ?s=CODE، يجيب التاجر من Firestore، ويبدّل العنوان/الوصف/الصورة.

## التركيب (يحتاج الدومين على Cloudflare)
1. npm i -g wrangler && wrangler login
2. من هذا المجلد: wrangler deploy
3. تأكد سجل tajerly.shop في Cloudflare DNS عليه السحابة البرتقالية (Proxied).
4. جرّب الرابط، ولتحديث كاش تيليجرام: ارسل الرابط لـ @WebpageBot.

## شكل الوصف
- لو التاجر كاتب وصف: يُستخدم وصفه.
- غير هيك: "متجر مختص ببيع {الفئة} — منها: {أمثلة منتجات} في {المحافظة}".
- النهاية دائماً توقيع المنصة: "تاجرلي: منصة عراقية لبناء المتاجر الإلكترونية مجاناً بدون اشتراك شهري، مع إدارة الطلبات والشحن والحسابات".

## روابط المنتجات والصور (تحديث)
- رابط منتج (`?s=CODE&product=ID`) يطلع بمعاينة المنتج: اسمه وسعره ووصفه وصورته (بدل معاينة المتجر العامة).
- الصور مخزنة base64 داخل مستند التاجر، فالـ Worker يقدّمها من `/_og/img?s=CODE[&product=ID]` (يفكّ base64 ويرجّعها كصورة PNG/JPEG/WebP). صور SVG (مثل المتجر التجريبي) ما تدعمها واتساب فتطلع المعاينة بدون صورة.
- بعد النشر: `wrangler deploy` من هذا المجلد، وبعدها أرسل رابط منتج لنفسك بواتساب أو لـ @WebpageBot (تيليجرام) أو Sharing Debugger (فيسبوك) لتحديث الكاش.
- المتاجر بدومين خاص (`customDomain`) ما يغطيها هذا الـ Worker لأنه يعمل على tajerly.shop فقط.
